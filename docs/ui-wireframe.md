# UI Wireframe - Spine Workbench v1

## 1. 目标
第一版界面重点不是华丽，而是把单图到导出的流程做顺。

## 2. 主界面结构
建议采用三栏布局。

### 左侧：资源与流程区
- 导入图片按钮
- 当前项目/角色信息
- 流程步骤列表
  - 导入
  - 拆件建议
  - 人工修正
  - 骨点调整
  - 导出

### 中间：主画布区
- 显示当前角色图
- 支持缩放
- 支持拖拽平移
- 支持显示拆件框/遮罩
- 支持显示骨点和骨骼连线

### 右侧：属性与编辑区
根据当前步骤切换内容。

#### 在拆件步骤
- 部件列表
- 选中部件信息
- 合并/拆分操作
- 命名编辑

#### 在骨点步骤
- 骨点列表
- 当前骨点坐标
- 父子关系
- 可见性开关

## 3. 底部区
- 当前提示信息
- 校验提醒
- 导出按钮
- 保存草稿按钮

## 4. MVP 必须有的页面/状态
### 页面 1：空状态页
- 显示“导入图片”主入口
- 简短说明第一版支持什么

### 页面 2：编辑页
- 三栏主编辑区
- 支持步骤切换

### 页面 3：导出确认页
- 显示导出目录
- 显示导出内容摘要
- 确认导出

## 5. 交互原则
- 尽量少弹窗
- 重要操作要可撤销
- 当前步骤要明显
- 所有导出内容要可预览

## 6. 第一版不追求
- 炫酷动效
- 多窗口复杂布局
- 团队协同界面
- 大量配置项
