# Interaction Flow - Spine Workbench v1

## 1. 主流程

### Step 1：导入图片
用户导入单张角色图。

系统动作：
- 加载图片
- 记录项目草稿
- 展示基础信息

### Step 2：自动拆件建议
系统对图片进行初步分析，生成可拆分区域建议。

系统输出：
- 候选部件区域
- 初步命名建议
- 可能问题提示

### Step 3：人工修正拆件
用户对自动建议结果进行编辑。

用户可操作：
- 删除错误区域
- 合并区域
- 拆分区域
- 重命名部件
- 调整层级顺序

### Step 4：骨点建议
系统根据部件结果生成骨点和骨架草稿。

系统输出：
- 关节点建议
- 骨骼连接关系建议
- 基础骨骼树

### Step 5：人工修正骨点
用户拖拽和修正骨点。

用户可操作：
- 调整关节位置
- 修改父子关系
- 删除不需要的骨点
- 补充缺失骨点

### Step 6：导出预览
系统生成导出结果预览。

系统展示：
- 导出目录结构
- 部件清单
- 骨骼摘要
- 提醒项

### Step 7：正式导出
用户确认并导出到本地目录。

## 2. 关键状态
- 未导入
- 已导入未分析
- 已生成拆件建议
- 已完成拆件修正
- 已生成骨点建议
- 已完成骨点修正
- 已导出

## 3. MVP 要求
- 任意一步都应尽量能保存草稿
- 用户应随时知道自己处在哪个步骤
- 关键错误应在导出前暴露
