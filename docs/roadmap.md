# Roadmap - Spine Workbench

## Phase 0 - 定义阶段
目标：把产品边界收紧，避免一开始做成大而空的 AI 工具。

产出：
- PRD
- 路线图
- 任务清单
- 示例输入要求

## Phase 1 - MVP 原型
目标：打通从单张图片到标准化导出结果的最小闭环。

范围：
- 单图导入
- 图片展示
- 拆件建议
- 人工调整
- 骨点修正
- 导出结构化结果

成功标志：
- 能基于 1 到 3 个样例完成完整流程

## Phase 2 - 提升可用性
目标：让工具从“能跑”变成“能用”。

可能内容：
- 更稳定的拆件逻辑
- 更好的部件编辑体验
- 遮挡补全辅助
- 命名和层级模板
- 导出校验

## Phase 3 - 对接 Spine 工作流
目标：减少从工具输出到 Spine 正式制作之间的人工整理成本。

可能内容：
- 更完整的骨架描述
- Spine 兼容性验证
- 中间格式转换
- 与实际项目资源目录联动

## Phase 4 - 扩展能力
这阶段再考虑，不提前承诺。

可能方向：
- 视频动作参考提取
- 批量处理
- 项目级资源管理
- 团队协作
- AI 辅助补全增强
