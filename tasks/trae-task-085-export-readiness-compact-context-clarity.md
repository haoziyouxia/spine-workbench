# trae-task-085-export-readiness-compact-context-clarity

## 任务概述
在 082-084 已经提升压缩表达自解释性和断点节奏的基础上，继续补足极窄视口下压缩表达的上下文，让用户不仅看懂单个提示，还能更自然理解它与当前状态、统计信息之间的关系。

## 任务目标
1. 优化极窄视口下压缩表达与状态上下文之间的连接
2. 减少用户"看得懂字面但不确定对应哪部分信息"的情况
3. 保持轻量，不恢复成完整展开态

## 实现要求
1. 优先补足上下文理解，而不是继续增加信息密度
2. 只补真正影响判断的轻量连接信息
3. 保持 064-084 的交互逻辑一致

## 验收标准
- 用户能自然理解压缩表达与状态上下文的关系
- 不需要额外猜测对应关系
- 保持轻量，不增加视觉负担

## 实现方案

### 核心思路
通过添加轻量的连接提示和视觉引导，让压缩表达与状态上下文之间的关系更清晰。

### 具体实现
- 为压缩统计项添加状态上下文提示
- 使用颜色和位置建立视觉连接
- 添加微妙的分隔符或连接线

## 交付结果

### 修改文件
1. `app/src/renderer/components/ExportPreview.tsx` - 添加上下文连接提示
2. `app/src/renderer/index.css` - 优化上下文连接样式
3. `tasks/trae-task-085-export-readiness-compact-context-clarity.md` - 任务文件

### 验证方法
1. 在 `app/` 目录运行 `npm run build` 确认构建成功
2. 调整浏览器宽度到极窄（420px 以下）
3. 验证压缩表达与状态上下文的关系清晰易懂
