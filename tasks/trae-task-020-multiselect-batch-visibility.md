# Trae Task 020 - Multi-Select And Batch Visibility

## 背景
当前编辑器已经有稳定的单选、复制、层级和 bone-part 关联。下一步可以补少量高价值的批量操作，提高处理多个 part 时的效率。

## 本次任务目标
增加基础多选能力和批量可见性切换。

## 本次只做这些
1. 支持基础多选（例如 Ctrl/Shift 辅助选择，或清晰的替代方案）
2. 在列表或画布中能看到多选状态
3. 支持对多选 part 批量切换 visible
4. 保持现有单选逻辑仍然稳定
5. 保存/加载/导出不被破坏

## 要求
- 第一版多选能力可以尽量简单
- 不要上复杂框选群组系统
- 重点是提升基础操作效率

## 验收标准
- 用户可选中多个 part
- 可对多个 part 执行批量可见性切换
- 单选和多选状态清楚、不混乱
