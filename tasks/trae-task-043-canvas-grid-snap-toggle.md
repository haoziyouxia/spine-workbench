# Trae Task 043 - Canvas Grid And Snap Toggle

## 背景
当前已经有较完整的手工编辑能力。下一步可以补一些轻量编辑辅助，让 bbox 和对象摆放更稳一点。

## 本次任务目标
增加基础网格显示和吸附开关。

## 本次只做这些
1. 在画布上提供可开关的基础网格显示
2. 提供吸附开关，用于 bbox 移动/缩放时的基础对齐辅助
3. 第一版吸附规则保持简单，例如固定步长吸附
4. 确保开关状态清楚可见

## 要求
- 第一版只做轻量辅助
- 不要实现复杂参考线系统
- 不要破坏现有自由编辑体验

## 验收标准
- 用户可开关网格显示
- 用户可开关基础吸附
- 吸附行为简单稳定，可感知
