# Trae Task 013 - Part Bounding Box Editing

## 背景
只靠创建 part 还不够。下一步需要让用户能直接编辑 part 的基础空间信息，尤其是 bbox，这样后面才有可能逐步替代 mock 数据并过渡到半真实拆件流程。

## 本次任务目标
为 part 增加基础 bbox 编辑能力。

## 本次只做这些
1. 在属性区显示当前 part 的 bbox 信息：
   - x
   - y
   - width
   - height
2. 允许用户手动修改这些值
3. 修改后主画布上能有基础可视化反馈（例如矩形框或占位框）
4. 保证修改结果可保存、可加载、可导出

## 要求
- 第一版可先用简单矩形框表示
- 不要求复杂拖拽框选交互
- 重点是数据链路和基础可视反馈

## 不要做这些
- 不要在这一轮实现智能选区
- 不要提前做复杂多边形编辑

## 验收标准
- 用户可以编辑 bbox 数值
- 画布能看到对应的基础框反馈
- 保存/加载/导出后的 bbox 数据一致
