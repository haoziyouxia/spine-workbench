# Trae Task 060 - Export Readiness Critical Summary Idle State

## 背景
在任务059的基础上，已经实现了关键问题摘要数字联动。本任务需要优化"没有关键问题时"的表现，让关键问题摘要在无阻塞项时自然弱化，不再给用户制造不必要的紧张感。

## 本次任务目标
优化关键问题摘要在"0个阻塞问题"时的表现，让无关键问题时的摘要状态更轻、更自然。

## 本次只做这些
1. 优化关键问题摘要在"0个阻塞问题"时的表现
2. 让无关键问题时的摘要状态更轻、更自然
3. 保持轻量，不做复杂动画或庆祝效果
4. 与现有计数、联动、折叠逻辑兼容

## 实现范围
- 无阻塞问题时的错误统计区域样式调整
- 弱化警示视觉表达
- 添加轻量文案说明当前状态

## 实现要求
1. 当阻塞问题数为0时，关键问题摘要应有明确但弱化的状态表达
2. 不要继续使用高警示视觉去表达"无关键问题"状态
3. 补充轻量文案，帮助用户理解当前已解除阻塞
4. 保持与058、059的点击逻辑兼容
5. 不要引入庆祝弹窗、复杂动效或额外面板

## 明确不做
- 大型成功页
- 复杂庆祝动画
- 额外概览面板
- 与导出准备度无关的大改

## 验收标准
- 无关键问题时，摘要不再制造紧张感
- 用户仍然能理解"当前阻塞已解除"
- 与已有关键问题摘要、点击联动和分组逻辑兼容
- 交互和视觉保持轻量自然

---

## 实现方案

### 空状态弱化机制
- 当错误数为0时，错误统计区域使用中性/成功色系
- 将"错误 (阻塞导出)"改为"就绪"或类似中性表达
- 添加轻量状态说明
