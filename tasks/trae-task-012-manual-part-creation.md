# Trae Task 012 - Manual Part Creation

## 背景
当前 parts 仍主要依赖 mock 或占位数据。下一阶段需要先让工具具备最基础的手工 part 创建能力，逐步摆脱纯 mock 状态。

## 本次任务目标
在现有编辑器中加入最小可用的手工创建 part 能力。

## 本次只做这些
1. 提供“新增 part”入口
2. 新增 part 时生成基础数据结构
3. 允许用户输入或修改：
   - part 名称
   - part 类型
   - zIndex
   - visible
4. 新建 part 后，列表和属性区能正确显示
5. 与当前状态管理和导出逻辑保持兼容

## 要求
- 第一版可先不绑定真实图像裁切
- 可以先生成一个基础 bbox 占位
- 重点是把真实 part 数据链路打通

## 不要做这些
- 不要在这一轮实现自动拆件
- 不要在这一轮实现复杂图像分割

## 验收标准
- 用户可以手动新增一个 part
- 新增后能在列表中看到并编辑基础字段
- 不会破坏当前导出与保存逻辑
