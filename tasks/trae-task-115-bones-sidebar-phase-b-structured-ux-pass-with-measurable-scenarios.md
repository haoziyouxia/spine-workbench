## 阶段目标
完成 bones 侧栏阶段B：结构化体验收口，以“场景可复现”作为验收主标准。

## 本章范围（仅限）

## 量化验收标准
1. 回写时 `Current Task` 必须为 **115**。
2. 提供**6个可复现场景**（编号 S1-S6），每个场景包含：
   - 前置条件
   - 操作步骤（≤3步）
   - 预期结果（1句）
3. 6个场景必须覆盖：
   - 未选中空状态（至少1个）
   - 选中骨骼详情态（至少2个）
   - 列表操作反馈（至少2个）
   - 危险操作提示（至少1个）
4. `npm run build` 再执行一次并记录结果。
