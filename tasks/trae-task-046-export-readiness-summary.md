# Trae Task 046 - Export Readiness Summary

## 背景
当前已经有较完整的导出校验和问题修复流程。下一步可以补一个更聚合的导出准备摘要，让用户在导出前更快知道当前项目成熟度。

## 本次任务目标
增加导出准备摘要信息。

## 本次只做这些
1. 在导出区域显示简短 readiness summary
2. 至少总结这些信息：
   - part 数量
   - bone 数量
   - 未关联 bone 的 part 数量
   - 当前错误/警告数量
3. 用简洁方式表达是否“适合导出”
4. 保持与现有校验逻辑一致

## 要求
- 第一版只做信息聚合，不做复杂评分系统
- 文案直接清楚

## 验收标准
- 用户在导出前能快速理解当前项目状态
- readiness summary 与现有校验数据一致
- 不与现有详细问题面板冲突
