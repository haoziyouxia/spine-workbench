# Trae Task 021 - Keyboard Shortcuts For Core Editing

## 背景
当前核心编辑能力已逐步建立。下一步补上少量高频快捷键，可以显著提升编辑体验。

## 本次任务目标
为当前编辑器加入最小一组高价值快捷键。

## 本次只做这些
1. Delete / Backspace 删除当前选中 part
2. Ctrl/Cmd + D 复制当前选中 part
3. Esc 退出创建模式或取消当前选择
4. 如果存在输入框焦点，避免误触发全局快捷键
5. 在 README 或界面中简单说明当前支持的快捷键

## 要求
- 快捷键范围先控制住
- 不要一次做太多组合键
- 保持行为和当前 UI 操作一致

## 验收标准
- 核心快捷键可用
- 不会明显影响输入框编辑
- 行为与按钮操作结果一致
