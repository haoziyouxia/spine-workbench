# Trae Task 015 - BBox Drag And Resize

## 背景
当前 bbox 主要通过数值输入编辑。下一步需要把 bbox 变成更像编辑器的直接交互对象。

## 本次任务目标
实现画布上对 part bbox 的拖拽移动和基础缩放。

## 本次只做这些
1. 选中 part 后，在画布上显示可交互的 bbox
2. 支持拖动 bbox 改变位置
3. 支持通过基础控制点或简化方式调整宽高
4. 修改结果实时同步到属性面板中的 bbox 数值
5. 修改结果保持与保存/加载/导出一致

## 要求
- 第一版先支持最基础的拖拽和缩放即可
- 不要求做复杂吸附或参考线
- 交互状态要清楚，避免误操作

## 不要做这些
- 不要做复杂旋转框
- 不要做多选编辑
- 不要做高级对齐系统

## 验收标准
- 用户能直接在画布上移动 bbox
- 用户能直接调整 bbox 尺寸
- 属性面板与画布反馈同步一致
