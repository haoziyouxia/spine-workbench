# Trae Task 006 - Draft Save And Load

## 背景
当前 Spine Workbench 已有导入、画布、部件面板和骨点编辑原型，但还缺少草稿持久化能力。没有这一步，当前项目只能一次性试玩，不利于继续迭代。

## 本次任务目标
为 MVP 加入基础的草稿保存和草稿加载能力。

## 本次只做这些
1. 为当前项目生成一个可保存的草稿数据结构
2. 支持手动保存草稿到本地 JSON 文件
3. 支持从本地 JSON 文件重新加载草稿
4. 加载后恢复：
   - 当前项目基本信息
   - 图片信息（如当前方案无法直接恢复原图，可明确限制）
   - parts 数据
   - bones 数据
   - 当前步骤状态
5. 在界面中提供“保存草稿”和“加载草稿”入口

## 要求
- 先用清晰的 JSON 结构
- 不要引入复杂数据库
- 如果图片二进制不适合直接进草稿，允许采用路径引用或明确限制
- 保持代码结构清晰

## 不要做这些
- 不要实现云同步
- 不要实现自动保存
- 不要做复杂版本管理

## 验收标准
- 可以手动保存草稿
- 可以手动加载草稿
- 加载后 parts、bones、当前步骤基本恢复
- 如果图片恢复有局限，界面要明确提示
