# Trae Task 007 - Export Preview And Package Skeleton

## 背景
当前 MVP 已有基本编辑交互，但导出仍是占位。下一步需要至少把导出预览和导出目录骨架先搭起来，让流程真正闭环。

## 本次任务目标
实现导出预览页面和标准化导出目录骨架生成。

## 本次只做这些
1. 增加导出预览视图或导出确认区域
2. 在导出前展示：
   - 项目名
   - parts 数量
   - bones 数量
   - 当前步骤/状态
   - 即将导出的目录结构摘要
3. 生成基础导出目录骨架，参考现有文档中的 export-format 约定
4. 导出基础 JSON 文件骨架，例如：
   - manifest.json
   - bones.json
   - hierarchy.json
   - notes.json
5. 暂时允许 parts 图片和 preview 仍为占位或简化实现，但要明确说明

## 要求
- 导出结果尽量人类可读
- 目录结构清楚
- 与 docs/export-format.md 尽量保持一致

## 不要做这些
- 不要实现复杂二进制格式
- 不要承诺直接生成成熟 Spine 工程
- 不要在这一轮做自动拆件算法

## 验收标准
- 用户可以看到导出前预览摘要
- 可以导出一个清晰的目录骨架
- JSON 文件能反映当前项目数据的核心结构
- 如果某些内容仍为占位，必须在结果或说明中体现
