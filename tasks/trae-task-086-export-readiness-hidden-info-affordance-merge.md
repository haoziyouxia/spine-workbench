# trae-task-086-export-readiness-hidden-info-affordance-merge

## 任务概述
若 085 后仍存在隐藏信息提示与主状态区略微割裂的问题，本章继续把显露线索和主状态表达做更自然的融合，减少"这里又多了一个小提示块"的感觉。

## 任务目标
1. 优化隐藏信息提示与主状态区的融合感
2. 减少额外小块带来的割裂感
3. 不引入复杂交互系统

## 实现要求
1. 线索要更自然嵌入现有结构
2. 不制造新的视觉噪音
3. 保持 064-085 一致性

## 验收标准
- 用户能自然感知到有隐藏信息
- 线索不突兀，与主状态区融合良好
- 保持轻量，不引入复杂系统

## 实现方案

### 核心思路
将隐藏信息提示融入现有的统计行结构，使其成为自然的一部分。

### 具体实现
- 将隐藏提示与统计项统一样式
- 使用相同的间距和布局方式
- 减少视觉突兀感

## 交付结果

### 修改文件
1. `app/src/renderer/index.css` - 优化隐藏信息提示样式
2. `tasks/trae-task-086-export-readiness-hidden-info-affordance-merge.md` - 任务文件

### 验证方法
1. 在 `app/` 目录运行 `npm run build` 确认构建成功
2. 调整浏览器宽度到极窄（420px 以下）
3. 验证隐藏信息提示与主状态区融合自然
