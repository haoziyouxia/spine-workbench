# Trae Task 055 - Export Readiness Sticky Critical Summary

## 背景
在任务054的基础上，已经实现了空状态引导。本任务需要添加粘性关键摘要，让用户在滚动时始终能看到最关键的问题摘要信息。

## 本次任务目标
为导出准备度区域添加粘性固定的关键摘要，确保用户在处理大量问题时始终能看到最关键的信息。

## 本次只做这些
1. 添加粘性定位的关键摘要栏
2. 显示最关键的未解决问题数量
3. 提供快速跳转到问题区域的入口
4. 保持轻量，不做复杂布局

## 实现要求
1. 粘性固定在顶部或区域顶部
2. 显示关键指标（错误数、警告数）
3. 与现有设计风格保持一致
4. 不要引入复杂的固定定位系统

## 明确不做
- 复杂的多栏布局
- 全局固定导航
- 复杂的滚动监听逻辑
- 大型信息面板

## 验收标准
- 用户滚动时关键摘要保持可见
- 快速了解当前问题状态
- 视觉上与整体设计协调
- 保持轻量不臃肿
