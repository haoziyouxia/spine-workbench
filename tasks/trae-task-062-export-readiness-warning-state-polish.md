# Trae Task 062 - Export Readiness Warning State Polish

## 背景
在任务061的基础上，已经区分了三种状态：阻塞、可导出但建议优化、完全就绪。本任务需要继续打磨中间态的表达，提升文案和视觉一致性。

## 本次任务目标
优化中间态（可导出但建议优化）的文案和视觉表达，让用户更容易理解"可以导出，但最好再处理一下"。

## 本次只做这些
1. 优化中间态的文案表达
2. 微调关键摘要和 readiness 区域的视觉一致性
3. 保持轻量，不做复杂扩展
4. 与现有逻辑兼容

## 实现范围
- 中间态的文案优化
- 图标和色彩层级微调
- 提示语一致性增强

## 实现要求
1. 中间态文案清楚表达"可导出"和"仍建议优化"两个信息点
2. 关键摘要区域与 readiness 区域表达一致
3. 优先做轻量微调
4. 不重做三态结构
5. 保持与现有逻辑兼容

## 明确不做
- 新增第四种状态
- 复杂评分体系
- 大型状态面板
- 与导出准备度无关的大改

## 验收标准
- 用户更容易理解"可导出但建议优化"的含义
- 中间态表达一致
- 不会和其他状态混淆
- 交互和视觉保持轻量自然

---

## 实现方案

### 中间态优化
- 使用更清晰的图标（⚠ 警告图标）
- 优化文案表达，明确"可导出"和"建议优化"
- 调整色彩层级，既不乐观也不阻塞
