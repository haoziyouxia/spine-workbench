# Trae Task 018 - Part Duplicate And Ordering

## 背景
当前已有 part 创建和基础编辑能力，但实际生产里常常需要快速复制部件并调整前后层级。下一步需要补上这些常用操作。

## 本次任务目标
为 part 增加复制和更顺手的层级调整能力。

## 本次只做这些
1. 增加“复制当前 part”能力
2. 复制后生成新的唯一 id
3. 新 part 默认复制原 part 的核心字段：
   - name
   - type
   - bbox
   - zIndex
   - visible
4. 提供更直观的层级调整操作，例如：
   - 上移一层
   - 下移一层
5. 调整结果同步到画布显示和导出结构

## 要求
- 第一版不需要复杂批量操作
- 重点是稳定、清楚、可验证

## 验收标准
- 用户可以复制一个 part
- 复制结果可见且不覆盖原 part
- 层级调整后画布显示和导出顺序一致
