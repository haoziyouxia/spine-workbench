# Trae Task 048 - Export Readiness Targeted Repair

## 背景
在任务047的基础上，已经实现了导出准备度的行动提示和基础交互闭环。本任务需要进一步细化，针对不同类型的问题提供更精确的修复入口。

## 本次任务目标
让不同类型的问题能对应更贴切的处理方式，减少用户看见问题但不知道改哪的情况。

## 本次只做这些
1. 针对未关联部件问题：提供更精确的定位和批量关联操作
2. 针对缺少骨骼问题：提供跳转到骨骼编辑的快捷入口
3. 针对可修复警告：提供最小化快捷修复操作
4. 让问题处理与编辑区域的联动更明确

## 实现要求
1. 至少两类问题拥有不同的处理动作
2. 问题类型与跳转目标精确匹配
3. 保持界面清晰，不臃肿

## 明确不做
- 自动拆件、自动骨骼生成
- 复杂评分系统、大型工作流面板
- 脱离导出准备度卡片的重型交互

## 验收标准
- 不同类型问题有不同处理方式
- 至少两类问题处理动作有明显区分
- 用户能更快从"看到问题"进入"开始修"
- 交互增量真实可感，但整体仍保持轻量
