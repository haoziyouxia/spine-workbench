# Trae Task 063 - Export Readiness State Action Copy Alignment

## 背景
在任务062的基础上，已经进一步区分了三种状态的文案和视觉。本任务需要整理状态按钮文案与实际动作的一致性，避免用户误解点击结果。

## 本次任务目标
优化不同状态下按钮文案与实际动作之间的一致性，让用户能准确预期点击后的行为。

## 本次只做这些
1. 检查并优化按钮文案与实际动作的一致性
2. 优先关注"查看阻塞问题"、"查看建议优化项"等按钮
3. 让按钮名称更贴近点击后的真实结果
4. 保持轻量，不做复杂扩展

## 实现范围
- 关键摘要区域的按钮文案优化
- readiness 区域的按钮文案优化
- 确保动作本质是展开分组时，文案不误导成"修复"或"处理完成"

## 实现要求
1. 按钮文案要能准确预期点击后会发生什么
2. 如果动作是展开分组，文案要说清楚是"展开"或"查看"
3. 如果动作是定位或查看，文案要说清楚是"定位"或"查看"
4. 保持与现有交互逻辑一致
5. 不引入复杂新按钮体系

## 明确不做
- 新增复杂动作流
- 自动修复系统
- 额外弹窗向导
- 与导出准备度无关的大改

## 验收标准
- 用户看到按钮文案时，能更准确预期点击后的行为
- 各状态的动作表达更一致
- 文案调整与真实交互一致
- 交互保持轻量自然

---

## 实现方案

### 按钮文案优化
- "查看阻塞问题" → "展开阻塞问题"（更准确表达动作本质）
- "查看建议优化项" → "展开建议优化项"（更准确表达动作本质）
- 确保所有按钮文案与实际动作一致
