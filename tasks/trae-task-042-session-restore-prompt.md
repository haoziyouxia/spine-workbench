# Trae Task 042 - Simple Session Restore Prompt

## 背景
当前已经有保存/加载和关闭前提醒。下一步可以补一个轻量体验优化，让用户重新打开工具时更容易继续上次工作。

## 本次任务目标
增加简单的会话恢复提示能力。

## 本次只做这些
1. 如果存在最近一次保存的草稿路径或可恢复信息，启动时给出轻量提示
2. 提供“继续打开最近草稿”或“忽略”选项
3. 不做复杂最近文件管理系统
4. 与当前保存/加载逻辑保持兼容

## 要求
- 第一版尽量简单
- 不要引入复杂历史列表
- 重点是让恢复工作更顺手

## 验收标准
- 用户重新打开应用时能看到简单恢复提示
- 可快速继续上次草稿或忽略
- 不影响现有启动流程稳定性
