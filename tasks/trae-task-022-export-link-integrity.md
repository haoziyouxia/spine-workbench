# Trae Task 022 - Export Integrity Check For Part-Bone Links

## 背景
当前导出结构已经包含更完整的 part 数据与 boneId。下一步需要补一层针对 bone-part 关系的数据一致性检查，避免导出出现悬空引用或明显错误。

## 本次任务目标
增强导出前对 bone-part 关联关系的完整性校验。

## 本次只做这些
1. 检查 part.boneId 是否引用了真实存在的 bone
2. 如果存在无效 boneId，给出明确错误或警告
3. 如果存在未关联 bone 的 part，按规则给出信息提示或警告
4. 在导出预览/校验区域展示这些结果
5. 与现有导出校验逻辑保持一致风格

## 要求
- 文案直接清楚
- 不要引入复杂规则系统
- 重点是导出数据稳定性

## 验收标准
- 无效 boneId 会被识别
- 校验结果能在导出前看到
- 合法关联关系不会被误判
