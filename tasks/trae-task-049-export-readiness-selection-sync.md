# Trae Task 049 - Export Readiness Selection Sync

## 背景
在任务048的基础上，已经实现了针对不同问题类型的精确处理动作。本任务需要进一步增强用户体验，让问题项、画布选中状态和属性面板形成联动。

## 本次任务目标
让用户在处理导出问题时，不只是被跳转到某一步，而是能立刻看见当前正在处理哪个部件或骨骼。

## 本次只做这些
1. 点击问题项后，相关部件/骨骼进入选中状态
2. 右侧属性面板同步显示对应对象信息
3. 画布视图聚焦到相关对象
4. 多对象场景提供明确的选中反馈

## 实现要求
1. 打通"问题项点击 → 选中对象 → 属性面板同步"链路
2. 优先增强现有机制，不重造状态系统
3. 界面反馈明显，但保持轻量

## 明确不做
- 复杂最近问题列表系统
- 独立的问题修复工作台
- 复杂批处理面板
- 自动修复引擎

## 验收标准
- 用户点击导出问题后，能明确知道当前正在处理哪个对象
- 画布、选中态、属性面板之间出现清晰联动
- 有可感知的当前对象上下文
