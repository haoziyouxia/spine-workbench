# Trae Task 025 - Canvas Labels And Overlay Clarity

## 背景
当前 part 越来越多，选择、多选、bone 关联等能力也越来越多。下一步需要适度增强画布叠加信息，让用户更容易看清当前对象和关系。

## 本次任务目标
提升画布上的标签和叠加信息清晰度。

## 本次只做这些
1. 在画布上为 part 提供简短标签显示（如名称或短标识）
2. 选中状态、多选状态、普通状态的视觉区分更清楚
3. 如果 part 已关联 bone，可提供轻量提示（例如标签中显示 bone 名或标识）
4. 避免标签过度遮挡画布

## 要求
- 第一版只做轻量信息增强
- 不要把画布做得过于嘈杂
- 重点是提升辨识度

## 验收标准
- 用户更容易分辨当前选中对象和其标识
- 多个 part 同时存在时，画布可读性更好
- 标签信息不会明显破坏编辑体验
