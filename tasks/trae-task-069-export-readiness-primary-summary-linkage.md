# trae-task-069-export-readiness-primary-summary-linkage

## 任务概述
在 068 已经把问题区里的首要项强调出来的基础上，继续补强顶部摘要与下方首要项之间的一致性，让用户在摘要区就能更明确感知"当前最需要处理的是哪一类、点下去会看到什么"。

## 任务目标
1. 优化顶部导出准备度摘要与首要问题/首要建议之间的信息呼应
2. 让摘要区的文案或轻量提示更具体，而不是只给出笼统状态
3. 继续保持轻量，不引入复杂流程、复杂统计面板或复杂说明块
4. 不推翻 064-068 已有结构，只做摘要与首要项的衔接增强

## 实现要求
1. 摘要区可以轻量提示"当前首要处理方向"或"点开后会优先看到什么"
2. 若存在阻塞问题，应优先在摘要中体现"当前先处理阻塞项"这类更具体的方向
3. 若只有建议项，应体现"可导出，但建议优先查看某类建议"这类更温和的方向
4. 若完全就绪，保持克制，不要为了对称强行增加噪音
5. 与 057-068 的导出准备度逻辑保持一致，不做大改

## 明确不要做
- 新页面
- 复杂规则引擎
- 多步骤向导
- 与导出准备度无关的大改

## 验收标准
- 用户在顶部摘要区就能更明确感知当前首要处理方向
- 摘要区与问题区的首要项呼应更自然，减少理解断层
- 整体仍然轻量、自然，不演变成复杂系统

## 实现方案

### 核心思路
在顶部导出准备度摘要区添加更具体的首要处理方向提示，与下方问题区的首要项形成呼应。

### 实现方法
1. 在 readiness-status 区域添加轻量提示文案
2. 根据状态（阻塞态/警告态/就绪态）显示不同的提示信息
3. 阻塞态：提示"先处理阻塞项以解除导出限制"
4. 警告态：提示"建议优先查看优化建议"
5. 就绪态：保持简洁，不增加额外提示

### 具体实现
- 在 status-desc 下方添加 summary-hint 区域
- 根据当前状态显示不同的提示内容
- 添加轻量样式，保持视觉一致性

3. `tasks/trae-task-069-export-readiness-primary-summary-linkage.md` - 任务文件

3. 创建无错误但有警告的项目，验证摘要区显示警告态提示
4. 创建无错误无警告的项目，验证摘要区保持简洁
5. 验证提示文案与下方首要项形成自然呼应

4. 就绪态保持简洁，不增加额外噪音
