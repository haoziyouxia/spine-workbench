# trae-task-077-export-readiness-hidden-stats-replacement-hints

## 任务概述
若 076 中确认在极窄视口下隐藏了部分统计项，本章继续补一个更轻量的替代提示机制，让用户知道被压缩掉的是什么，而不是静默消失。

## 任务目标
1. 为被隐藏或折叠的信息补充轻量替代提示
2. 保持提示极简，不抢主状态区注意力
3. 不引入复杂 tooltip 系统或弹层系统

## 实现要求
1. 提示要足够轻，不制造新的视觉噪音
2. 重点解决"信息突然消失"的理解断层
3. 保持 064-076 逻辑一致

## 验收标准
- 用户知道被隐藏的是什么内容
- 提示不干扰主状态区
- 保持轻量，不引入复杂系统

## 实现方案

### 核心思路
为被隐藏的统计项添加极简提示，让用户知道有信息被压缩。

### 具体实现
- 在统计行添加一个轻量的"更多"提示
- 提示内容简洁，不占用太多空间
- 使用微妙的视觉样式，不抢注意力

## 交付结果

### 修改文件
1. `app/src/renderer/components/ExportPreview.tsx` - 添加隐藏信息提示
2. `app/src/renderer/index.css` - 添加提示样式
3. `tasks/trae-task-077-export-readiness-hidden-stats-replacement-hints.md` - 任务文件

### 验证方法
1. 在 `app/` 目录运行 `npm run build` 确认构建成功
2. 调整浏览器宽度到极窄（420px 以下）
3. 验证隐藏统计项时有适当提示
4. 验证提示不干扰主状态区
