# trae-task-072-export-readiness-header-density-polish

## 任务概述
在 071 已经把顶部状态区的文案重复继续压缩后，进一步检查顶部状态区的视觉密度，看看是否还能在不损失信息的前提下让结构更紧凑、更好扫读。

## 任务目标
1. 检查状态区顶部卡片、下一步引导、统计行之间的视觉挤压与层级关系
2. 尝试减少不必要的留白、重复边框感或视觉断层
3. 保持信息完整，不为了紧凑而牺牲可读性
4. 不改动问题区主结构，不引入新模块

## 实现要求
1. 优先做轻量视觉整理，而不是大改配色体系
2. 让顶部区域更容易一眼扫完状态、方向、动作
3. 若某些块之间已经足够清晰，就不要为改而改
4. 保持 064-071 的交互逻辑一致，不做大改
5. 目标是更利落、更稳，不是更花哨

## 明确不要做
- 新页面
- 大规模视觉重构
- 新的复杂组件系统
- 与导出准备度无关的大改

## 验收标准
- 顶部状态区更易扫读，视觉密度更平衡
- 信息完整性不下降，交互逻辑不受影响
- 整体仍然轻量、自然，不演变成复杂系统

## 实现方案

### 核心思路
检查并优化顶部状态区的视觉密度，减少冗余的间距和边框，让信息层次更清晰。

### 视觉优化策略
1. 减少 readiness-header 内部的垂直间距
2. 整合状态卡片和下一步引导，减少重复的边框
3. 优化统计行与其他区域的间距
4. 统一各模块的内边距和外边距

### 具体实现
- 调整 readiness-header 的 flex 布局和间距
- 合并状态卡片和下一步引导的边框样式
- 减少不必要的垂直留白
- 优化整体视觉层级

## 交付结果

### 修改文件
1. `app/src/renderer/index.css` - 优化顶部状态区的视觉密度
2. `tasks/trae-task-072-export-readiness-header-density-polish.md` - 任务文件

1. 在 `app/` 目录运行 `npm run build` 确认构建成功
2. 查看顶部状态区的视觉效果，验证更紧凑、更好扫读
3. 验证信息完整性不受影响
4. 验证交互逻辑正常

### 相比 071 的增强
1. 优化了顶部状态区的视觉密度
2. 减少了不必要的留白和边框重复
3. 让状态区更容易一眼扫完
4. 保持信息完整和交互逻辑不变
