# Trae Task 031 - Duplicate Naming And Part List Readability

## 背景
当前已经支持复制 part，但随着部件数量增加，命名和列表可读性会逐步成为问题。下一步可以补一层轻量规范，让列表更容易读。

## 本次任务目标
优化复制命名和部件列表可读性。

## 本次只做这些
1. 复制 part 时采用更清楚的默认命名规则
2. 避免短时间内多次复制导致名称混乱
3. 在部件列表中适度增强关键信息展示，例如：
   - 名称
   - 类型
   - 可见性
   - 是否已关联 bone
4. 保持列表不显得过度拥挤

## 要求
- 第一版只做轻量优化
- 不要上复杂命名规则编辑器

## 验收标准
- 连续复制后的名称更容易理解
- 列表可读性更好
- 不影响现有选择和编辑行为
