# Trae Task 030 - Selection Summary And Status Bar

## 背景
当前编辑器已经有单选、多选、批量操作和定位修复。下一步需要一个轻量状态汇总区，让用户随时知道当前选中了什么、处于什么模式。

## 本次任务目标
增加基础选择摘要和状态栏信息。

## 本次只做这些
1. 显示当前选中数量
2. 显示当前模式（编辑/创建等）
3. 单选时显示当前对象名称
4. 多选时显示多选摘要
5. 放在不打扰主编辑区域的位置

## 要求
- 信息简洁
- 不要做复杂面板系统
- 重点是增强编辑可感知性

## 验收标准
- 用户能快速知道当前选择状态
- 当前模式清楚可见
- 不影响现有布局稳定性
