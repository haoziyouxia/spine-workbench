# Trae Task 045 - Restore Prompt Safety And Edge Cases

## 背景
当前已经有会话恢复提示。下一步需要补一些边界情况处理，避免恢复逻辑在草稿不存在或路径失效时给用户错误体验。

## 本次任务目标
增强会话恢复提示的健壮性。

## 本次只做这些
1. 检查记录的最近草稿路径是否仍然有效
2. 路径失效时给出清楚提示并允许清除记录
3. 避免启动时反复弹出无效恢复提示
4. 与当前 localStorage 记录逻辑兼容

## 要求
- 第一版先把最常见边界处理好
- 不要扩展成完整最近文件管理系统
- 重点是避免坏提示和无效恢复

## 验收标准
- 无效草稿路径能被识别
- 用户不会反复被无效恢复提示打扰
- 恢复流程在异常情况下仍然清楚
