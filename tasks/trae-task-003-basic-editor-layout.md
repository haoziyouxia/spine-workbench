# Trae Task 003 - Basic Editor Layout Wiring

## 背景
在项目脚手架和图片导入能力有基础后，需要把 MVP 编辑器的整体结构搭起来。

## 本次任务目标
把三栏布局和基础步骤状态串起来，为后续拆件和骨点功能预留位置。

## 本次只做这些
1. 左侧显示流程步骤列表
2. 中间显示主画布容器
3. 右侧显示属性面板占位
4. 顶部或底部显示当前项目名称和状态
5. 在不同步骤切换时，右侧占位内容跟着变化

## 建议步骤
- 导入
- 拆件建议
- 人工修正
- 骨点调整
- 导出

## 不要做这些
- 不要提前实现真实拆件算法
- 不要提前实现真实骨骼算法
- 不要过度美化 UI

## 验收标准
- 三栏结构清楚
- 流程步骤可见
- 当前步骤高亮明确
- 状态切换不会让页面混乱
