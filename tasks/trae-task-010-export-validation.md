# Trae Task 010 - Export Validation And Warnings

## 背景
当前导出已经有基本流程，但缺少导出前校验。作为生产工具，至少要在导出前明确提示用户哪些内容缺失、哪些仍是占位。

## 本次任务目标
在导出前加入基础校验和告警提示。

## 本次只做这些
1. 在导出预览或导出前增加校验结果区域
2. 至少检查以下项目：
   - 是否已导入图片
   - 是否存在 parts 数据
   - 是否存在 bones 数据
   - 当前是否仍使用 mock / 占位数据
   - 是否存在未实现导出内容
3. 区分信息级提示、警告、阻断错误
4. 阻断错误时，不允许正式导出
5. 警告项允许继续导出，但要清楚提示

## 要求
- 文案直接、易懂
- 不要做复杂规则引擎
- 校验逻辑保持可维护

## 验收标准
- 用户在导出前能看到校验结果
- 明显缺失时会阻止导出
- 占位或不完整内容会有警告提示
- 导出流程比之前更清楚、更可靠
