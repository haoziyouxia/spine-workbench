# Trae Task 047 - Export Readiness Action Loop

## 背景
当前已经有导出准备度摘要，可以显示项目状态。下一步需要补齐从发现问题到处理问题的最小操作闭环，让用户不只是看到状态，还能快速知道下一步该做什么。

## 本次任务目标
增强导出准备度摘要的交互性，提供明确的行动提示和快速定位能力。

## 本次只做这些
1. 在导出准备度摘要中，为关键问题提供明确行动提示
2. 对高优先级问题，支持最小化定位跳转或聚焦引导
3. 优先处理这些场景：
   - 未关联部件：提供快速关联入口
   - 明显错误项：提供定位引导
   - 可修复的警告项：提供修复提示
4. 保持实现轻量，不扩展为复杂系统

## 要求
- 第一版只做最小闭环
- 不要做复杂评分系统或工作流引擎
- 重点是让用户知道"接下来该做什么"

## 验收标准
- 用户在导出前看到问题后，能明显知道"接下来该做什么"
- 至少对一种高价值问题提供直接定位或操作入口
- 不只是展示文案，而是形成实际可用的交互闭环

## 与 046 的衔接
046 提供了准备度摘要的展示能力，本任务在其基础上添加行动引导和交互能力。
