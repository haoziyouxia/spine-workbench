# Trae Task 004 - Parts Panel Prototype

## 背景
在 MVP 中，用户需要能看到当前拆件结果，并对部件进行基础查看和编辑。

## 本次任务目标
实现右侧或侧边的部件列表面板原型。

## 本次只做这些
1. 显示部件列表
2. 支持选中某个部件
3. 显示部件基础信息
   - name
   - type
   - zIndex
   - visible
4. 提供基础占位操作按钮
   - 重命名
   - 合并
   - 删除

## 要求
- 先使用 mock 数据也可以
- 结构清晰，便于后续接真实数据
- 不要实现真正图像切割算法

## 验收标准
- 能看到部件列表
- 选中部件后右侧信息会变化
- 面板结构适合后续继续扩展
