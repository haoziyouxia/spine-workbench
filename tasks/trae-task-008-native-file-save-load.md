# Trae Task 008 - Native File Save And Load

## 背景
当前草稿保存/加载能力已经有了，但更偏浏览器式下载/上传逻辑。Spine Workbench 是桌面工具，下一步需要改成更原生的文件系统交互方式。

## 本次任务目标
把草稿保存/加载改成更符合 Electron 桌面应用习惯的本地文件操作。

## 本次只做这些
1. 保存草稿时，使用系统文件保存对话框选择保存路径
2. 加载草稿时，使用系统文件选择对话框选择草稿文件
3. 草稿文件格式继续沿用当前 JSON / `.spine-draft` 方案即可
4. 在界面中清楚反馈保存成功、加载成功、失败原因
5. 保持与当前项目数据结构兼容

## 要求
- 优先使用 Electron 能力完成
- 不要把逻辑继续做成浏览器下载行为
- 代码结构尽量清晰，必要时做 renderer 和 main 的职责分离

## 不要做这些
- 不要引入数据库
- 不要做自动保存
- 不要做最近文件列表

## 验收标准
- 用户可以通过系统保存对话框保存草稿
- 用户可以通过系统打开对话框加载草稿
- 保存和加载成功/失败有明确提示
- 原有草稿功能不被破坏
