# Trae Task 014 - Create Part By Drag

## 背景
当前已经支持手动创建 part 和数值编辑 bbox，但仍偏表单式操作。下一步需要让用户能直接在画布上通过拖拽矩形来创建 part。

## 本次任务目标
实现基于画布拖拽框选的 part 创建能力。

## 本次只做这些
1. 在画布中增加“创建 part”模式或入口
2. 用户拖拽一个矩形区域后，生成新的 part
3. 新建 part 自动带入 bbox：
   - x
   - y
   - width
   - height
4. 新建后自动选中该 part
5. 新建结果同步到列表、属性面板、保存/加载、导出链路

## 要求
- 第一版用简单矩形框即可
- 交互尽量直观
- 和现有 bbox 数据结构保持一致

## 不要做这些
- 不要做智能选区
- 不要做复杂多边形框选
- 不要在这一轮绑定真实图像裁切

## 验收标准
- 用户可以在画布上拖出一个矩形并创建 part
- 新 part 能在列表和属性区显示
- bbox 数据正确进入现有数据链路
