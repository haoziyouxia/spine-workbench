# Trae Task 029 - Validation Filter And Collapse Controls

## 背景
当前问题面板已经支持分组显示和跳转修复。下一步需要补一点轻量管理能力，避免问题变多时面板过于拥挤。

## 本次任务目标
为问题面板增加基础筛选和折叠控制。

## 本次只做这些
1. 支持按错误/警告/信息筛选显示
2. 每个分组支持折叠/展开
3. 显示每组问题数量
4. 保持与现有问题定位和修复逻辑兼容

## 要求
- 第一版保持简单直接
- 不要引入复杂查询系统

## 验收标准
- 用户可以快速筛选某一类问题
- 用户可以折叠不关心的分组
- 问题面板在问题较多时仍保持可读
