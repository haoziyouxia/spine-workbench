# Trae Task 009 - Real Export Directory

## 背景
当前导出功能已经有预览和打包骨架，但还不够像桌面生产工具。下一步先不要追求复杂 zip，而是做真实的本地导出目录。

## 本次任务目标
把导出功能改成输出一个真实的本地目录结构，而不是浏览器式下载包。

## 本次只做这些
1. 导出时使用系统目录选择或保存路径选择
2. 在本地生成真实导出目录
3. 至少生成这些 JSON 文件：
   - manifest.json
   - bones.json
   - hierarchy.json
   - notes.json
4. 目录结构尽量对齐 `docs/export-format.md` 的约定
5. 如果 parts/preview 仍未实现，允许目录为空或写入占位说明

## 要求
- 输出结果人类可读
- 目录结构清楚
- 和当前项目状态尽量对应

## 不要做这些
- 不要在这一轮实现自动拆件
- 不要承诺导出成熟 Spine 工程
- 不要先上复杂 zip 库和高级压缩流程

## 验收标准
- 用户可选择导出位置
- 本地能生成真实目录与 JSON 文件
- 导出结果能反映当前项目核心数据
- 未实现内容有明确占位说明
