# Trae Task 059 - Export Readiness Critical Count Linkage

## 背景
在任务058的基础上，已经实现了一键展开关键问题功能。本任务需要优化关键问题摘要的可理解性，让关键问题数量、摘要提示和实际分组内容之间的对应关系更直观。

## 本次任务目标
增强关键问题摘要的可理解性，让关键问题数量与实际分组内容之间的对应关系更直观。

## 本次只做这些
1. 优化关键问题摘要中的数量表达
2. 在摘要数字与关键问题分组之间建立更明确的联动或说明
3. 保持轻量，不做复杂统计系统
4. 与一键展开逻辑兼容

## 实现范围
- 关键问题摘要数字的优化显示
- 摘要数字区域的交互入口增强
- 轻量说明文字的添加

## 实现要求
1. 更明确地表达"当前有多少阻塞项"以及对应哪一组内容
2. 让摘要中的数字区域成为交互入口
3. 添加极轻量说明文字
4. 保持与现有分组、折叠、记忆、联动展开逻辑兼容

## 明确不做
- 复杂统计图表
- 独立概览面板
- 大型问题仪表盘
- 与导出准备度无关的大改

## 验收标准
- 用户更容易理解关键问题摘要里的数量含义
- 摘要数字和关键问题分组之间的关系更清晰
- 与现有一键展开和折叠逻辑兼容
- 交互保持轻量自然

---

## 实现方案

### 摘要数字联动机制
- 在统计区域的错误计数上添加点击事件，点击后展开关键问题分组
- 添加悬浮提示说明数字含义和点击后的行为
- 在数字旁边添加极轻量的说明文字
