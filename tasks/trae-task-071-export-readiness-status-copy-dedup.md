# trae-task-071-export-readiness-status-copy-dedup

## 任务概述
在 070 已经把摘要提示、下一步引导、动作按钮三层语义收拢后，继续压缩状态卡片本身的主副信息，减少同一状态被不同句式重复表达的问题，让顶部区域更干净、更利落。

## 任务目标
1. 检查状态标题、状态描述、摘要提示、下一步引导之间的重复信息
2. 尽量减少"同义重复"或"只换说法不增信息"的文案
3. 保持核心状态信息清晰，不因压缩而变得含糊
4. 不改变既有主结构，不新增复杂模块

## 实现要求
1. 优先删减重复表达，而不是新增更多修饰文案
2. 顶部区域要保持"状态判断 + 当前方向 + 下一步动作"三层，但每层各司其职
3. 阻塞态、警告态、就绪态都要检查是否有可压缩空间
4. 保持 064-070 的交互逻辑一致，不做大改
5. 目标是更利落，不是更花哨

## 明确不要做
- 新页面
- 新的复杂状态系统
- 大规模视觉重做
- 与导出准备度无关的大改

## 验收标准
- 顶部区域信息更利落，重复感继续下降
- 用户仍能快速理解状态、当前方向和下一步动作
- 整体仍然轻量、自然，不演变成复杂系统

## 实现方案

### 核心思路
分析当前状态卡片各层文案，找出重复表达，进行去重和压缩，让每层各司其职：
- 状态标题：简洁表达当前状态
- 状态描述：补充必要的数量信息
- 摘要提示：提示首要处理方向（可与状态描述合并或简化）
- 下一步引导：明确下一步动作

### 去重策略

| 状态 | 原状态标题 | 原状态描述 | 原摘要提示 | 优化后 |
|------|-----------|-----------|-----------|--------|
| **阻塞态** | 需要完善 | 存在 X 个阻塞问题，修复后才能导出 | 需要先修复阻塞问题 | 合并重复表达 |
| **警告态** | 可导出 | 可导出，但建议优化 X 项 | 建议优化后导出 | 合并重复表达 |
| **就绪态** | 完全就绪 | 所有检查已通过，可直接导出 | （不显示） | 简化描述 |

### 具体实现
- 简化状态描述，移除与摘要提示重复的内容
- 就绪态移除冗余的"可直接导出"表述
- 保持核心信息层级清晰
