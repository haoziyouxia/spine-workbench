# Trae Task 034 - Save Dirty State And Close Warning

## 背景
当前工具已经有原生保存/加载和较多编辑能力。下一步需要补一个基础“未保存修改”状态，避免用户误关窗口或误切换后丢数据。

## 本次任务目标
增加 dirty state 标记和基础离开提醒。

## 本次只做这些
1. 当项目发生编辑修改后，标记为未保存状态
2. 保存成功后清除未保存状态
3. 在界面中轻量显示当前是否有未保存修改
4. 当用户尝试关闭窗口或离开当前工作内容时，给出基础提醒

## 要求
- 第一版先做最核心提醒
- 不要做复杂自动保存系统
- 提醒文案要清楚直接

## 验收标准
- 编辑后能看到未保存状态
- 保存后状态恢复
- 关闭或离开时能收到明确提醒
