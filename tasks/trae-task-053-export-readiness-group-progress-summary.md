# Trae Task 053 - Export Readiness Group Progress Summary

## 背景
在任务052的基础上，已经实现了分组折叠功能。本任务需要为每个优先级分组添加进度摘要，让用户能快速了解每组问题的处理进度。

## 本次任务目标
为每个优先级分组添加进度摘要，显示已完成数/总数，帮助用户快速判断处理进度。

## 本次只做这些
1. 为每个优先级分组添加进度计数
2. 在分组标题中显示已完成数/总数
3. 添加简单的进度条或百分比显示
4. 保持轻量，不做复杂统计系统

## 实现范围
- 错误（error）分组的进度显示
- 警告（warning）分组的进度显示
- 提示（info）分组的进度显示

## 实现要求
1. 显示每组的问题总数和已处理数
2. 提供直观的进度反馈（进度条 + 百分比）
3. 与现有的折叠功能兼容
4. 不要引入复杂图表或统计面板

## 明确不做
- 复杂评分系统
- 大型统计仪表板
- 历史进度追踪
- 复杂数据可视化

## 验收标准
- 用户能快速了解每组问题的处理进度
- 进度显示清晰直观
- 与折叠功能无缝配合
- 保持轻量不臃肿

### 落点组件说明

**落点组件: ValidationResult.tsx**

**为什么落在这里：**
1. **职责匹配**：ValidationResult 组件负责展示所有校验结果，包括分组显示、过滤和折叠功能。进度摘要作为分组展示的一部分，自然应该放在这里。

2. **数据就近**：校验结果数据（`result.items`）直接在该组件中处理和分组，计算进度所需的数据就在此组件内，无需跨组件传递。

3. **视觉一致性**：分组头部已经包含了图标、标题、数量和折叠按钮，进度信息作为头部的延伸，保持视觉上的统一和紧凑。

4. **与折叠功能集成**：进度条显示在分组头部，用户折叠/展开分组时都能看到进度状态，符合用户预期。

5. **避免重复**：如果放在 ExportPreview 中，需要重新处理分组逻辑，而 ValidationResult 已经有完整的分组处理逻辑。
