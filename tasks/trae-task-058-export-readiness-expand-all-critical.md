# Trae Task 058 - Export Readiness Expand All Critical Issues

## 背景
在任务057的基础上，已经实现了摘要与分组的联动展开。本任务需要添加一个更直接的"查看全部关键问题"入口，让用户在存在多个阻塞项时，可以一键展开所有关键问题相关内容。

## 本次任务目标
为导出准备度区域增加"展开全部关键问题"入口，让用户在存在多个阻塞项时可一键看到完整关键问题列表。

## 本次只做这些
1. 增加"展开全部关键问题"轻量入口
2. 优先作用于高优先级/阻塞导出问题
3. 保持轻量，不做复杂全局控制面板
4. 与056的状态记忆、057的联动展开兼容

## 实现范围
- 关键问题组的一键展开功能
- 入口状态反馈（已展开/未展开）
- 与现有折叠逻辑兼容

## 实现要求
1. 至少支持关键问题组的一键展开
2. 如果当前关键问题组已展开，入口状态应自然反馈
3. 与状态记忆、联动展开兼容
4. 不要引入复杂"全部展开/全部收起"系统，聚焦关键问题
5. 用户操作后应明显感知到关键问题已全部可见

## 明确不做
- 全量分组控制面板
- 复杂批量导航系统
- 与导出准备度无关的大改
- 重型折叠管理设置

## 验收标准
- 用户在关键问题较多时，可一键看到全部阻塞问题
- 交互明确轻量，不会和现有折叠逻辑冲突
- 与既有状态记忆和联动展开机制兼容

---

## 实现方案

### 一键展开机制
- 在导出准备度区域添加"展开全部关键问题"按钮
- 点击时展开所有关键问题相关的分组
- 根据当前状态显示不同的按钮文案（展开/已展开）

- 添加一键展开关键问题的函数
- 在摘要区域添加操作入口

**文件: app/src/renderer/index.css**
- 添加一键展开按钮样式
