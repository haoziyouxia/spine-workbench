# 任务065：导出准备度关键摘要收敛与噪音控制优化

## 任务目标
在 064 已经优化项目总览信息层级与显著性的基础上，继续收敛导出准备度关键摘要中的信息噪音，让用户在第一屏只看到最值得先处理或先确认的内容，减少注意力被次要信息分散。

## 任务范围
1. 优化导出准备度关键摘要中信息块的保留与弱化策略
2. 让"当前最该处理的问题"比背景性统计更优先
3. 在问题较多和问题较少两种场景下，都保持摘要区简洁清楚
4. 保持轻量，不做重型仪表盘或复杂交互系统

## 实现要求
1. 优先减少第一眼噪音，不要只是继续堆更多视觉强调
2. 让关键摘要更聚焦"阻塞 / 建议 / 是否可继续导出"这类直接决策信息
3. 次要统计信息可以弱化，但不要完全破坏现有信息完整性
4. 保持与 057、058、059、062、063、064 的导出准备度交互逻辑一致
5. 不要引入复杂评分系统、复杂工作流面板、复杂筛选器、复杂设置系统

## 明确不要做
- 独立新页面
- 新的大型信息面板
- 多层复杂折叠体系
- 与导出准备度无关的大改

## 交付要求
1. 改了哪些文件
2. 如何验证
3. 当前限制是什么
4. 本任务相比 064 增强了什么
5. git status --short
6. git log -1 --stat

## 验收标准
- 用户进入导出准备度区域后，能更快识别"当前最值得先关注的内容"
- 摘要区比 064 更聚焦，不显得信息太满
- 阻塞、建议、就绪状态之间的优先级更稳定
- 保持轻量自然，不演变成复杂系统
