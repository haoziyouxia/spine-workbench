# trae-task-078-export-readiness-header-action-wrap-polish

## 任务概述
在 077 之后，继续检查顶部状态区在换行场景下的按钮、描述、统计行之间的节奏是否自然，避免窄视口虽然能放下，但换行后显得松散或别扭。

## 任务目标
1. 优化窄视口下动作按钮和说明文字的换行节奏
2. 减少因折行造成的块间突兀断层
3. 保持轻量，不重做结构

## 实现要求
1. 优先微调间距、对齐、换行策略
2. 不为单一极端尺寸写复杂特判系统
3. 保持 064-077 的整体一致性

## 验收标准
- 窄视口下换行后布局仍然自然
- 块间衔接顺畅，无突兀断层
- 保持轻量，不增加复杂度

## 实现方案

### 核心思路
优化窄视口下的换行布局，确保按钮和文字的折行自然。

### 具体实现
- 调整 flex-wrap 和对齐方式
- 优化间距，减少折行后的断层感
- 确保按钮和描述在折行后仍保持良好的视觉节奏

## 交付结果

### 修改文件
1. `app/src/renderer/index.css` - 优化换行布局和间距
2. `tasks/trae-task-078-export-readiness-header-action-wrap-polish.md` - 任务文件

### 验证方法
1. 在 `app/` 目录运行 `npm run build` 确认构建成功
2. 调整浏览器宽度，观察不同宽度下的换行效果
3. 验证换行后布局自然，无突兀断层
