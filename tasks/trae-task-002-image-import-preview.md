# Trae Task 002 - Image Import And Preview

## 背景
Spine Workbench 的第一版需要先打通最小闭环里的前两步：导入单张图片，并在主界面中完成展示。

## 本次任务目标
在已有项目脚手架基础上，实现图片导入和预览基础能力。

## 本次只做这些
1. 支持选择本地单张图片文件
2. 读取图片并显示在主画布区域
3. 画布支持基础缩放
4. 画布支持基础拖拽平移
5. 左侧流程区显示当前已导入状态
6. 右侧先保留占位信息区

## 要求
- 先支持 PNG
- 界面尽量简单
- 不要提前实现拆件逻辑
- 代码结构保持清晰

## 交付物
- 可以运行的图片导入和预览界面
- 基础状态管理
- 简单说明如何启动

## 验收标准
- 可以选择一张 PNG
- 选择后图片能显示在主画布
- 可以缩放和平移
- 不崩溃
