# Trae Task 032 - Undo And Redo For Core Part Editing

## 背景
当前编辑器已经具备较完整的 part 创建、移动、缩放、复制、删除和批量操作能力。下一步很值得补一个基础撤销/重做，让编辑体验更接近真正的生产工具。

## 本次任务目标
为核心 part 编辑操作增加基础 undo / redo。

## 本次只做这些
1. 支持对核心 part 操作进行撤销和重做，例如：
   - 创建
   - 删除
   - 移动 bbox
   - 调整 bbox 尺寸
   - 复制
   - 可见性切换
2. 提供基础按钮或快捷键入口
3. 撤销/重做后，画布、列表、属性区保持一致
4. 不破坏现有保存/加载/导出逻辑

## 要求
- 第一版可以只覆盖最核心 part 相关操作
- 不要求一次覆盖所有 bone 操作
- 重点是行为稳定、清楚

## 验收标准
- 用户可以执行至少一轮撤销和重做
- 撤销/重做后的 UI 和数据状态一致
- 不会明显引入编辑状态错乱
