# Trae Task 050 - Export Readiness Inline Fix Hints

## 背景
在任务049的基础上，已经实现了问题项点击后选中对象并同步属性面板。本任务需要进一步降低用户理解成本，提供更具体的修复提示。

## 本次任务目标
让用户在看到问题时，不只是知道"去哪里改"，还知道"应该怎么改"，减少思考成本。

## 本次只做这些
1. 为常见问题类型补充具体的inline修复提示
2. 优先覆盖：未关联部件、骨骼缺失、命名问题、可修复warning
3. 保持轻量，不做复杂表单或编辑器

## 实现要求
1. 至少两类问题显示不同的修复提示文本
2. 显示轻量推荐信息（建议步骤、检查字段、关联对象类型）
3. 加入轻量inline hint区块
4. 文案具体，避免空泛

## 明确不做
- 复杂内嵌编辑表单
- 自动修复引擎
- 复杂推荐算法
- 大型帮助中心面板

## 验收标准
- 用户能更容易理解"具体该怎么修"
- 至少两类问题有明显不同的修复提示
- 提示与已有动作一致
- 交互保持轻量
