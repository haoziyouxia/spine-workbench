# Trae Task 056 - Export Readiness Group State Memory

## 背景
在任务052的基础上，已经实现了分组折叠/展开功能。本任务需要让导出准备度区域记住用户最近一次的分组展开状态，减少用户重复操作的摩擦。

## 本次任务目标
让导出准备度区域记住用户最近一次的分组展开状态，在同一项目会话中再次进入导出步骤时自动恢复。

## 本次只做这些
1. 记住导出准备度中各优先级分组的最近展开/折叠状态
2. 用户在同一项目会话中再次进入导出步骤时恢复上次的分组状态
3. 默认策略合理，高优先级问题不会因为记忆状态而完全失去可见性
4. 保持轻量，不做复杂偏好系统

## 实现范围
- 关键（critical）分组状态记忆
- 推荐（recommended）分组状态记忆
- 可选（optional）分组状态记忆

## 实现要求
1. 支持关键/推荐/可选三组状态记忆
2. 如果存在阻塞导出的问题，高优先级分组应优先保持可见
3. 状态记忆在当前项目会话内有效
4. 不引入复杂设置项或配置面板
5. 复用已有状态机制，不重造大状态系统

## 明确不做
- 复杂用户偏好中心
- 全局设置页
- 跨项目同步配置
- 与导出准备度无关的大改

## 验收标准
- 用户重新进入导出步骤后，不需要反复手动展开相同分组
- 高优先级问题仍保持足够可见
- 行为自然，不引入复杂配置

---

## 实现方案

### 状态存储机制
- 使用 React useState 配合 useEffect 监听变化
- 在分组状态变化时更新记忆存储
- 进入导出步骤时读取记忆并恢复状态

### 高优先级保护策略
- 如果存在错误（error）级别问题，关键分组强制展开
- 只记忆用户主动操作的状态，不覆盖强制展开逻辑

**文件: app/src/renderer/components/ExportPreview.tsx**
- 在状态变化时保存分组展开状态到记忆
- 在组件挂载时读取并恢复分组状态

**文件: app/src/renderer/components/ValidationResult.tsx**
- 确保分组展开逻辑与状态记忆兼容
