# Trae Task 001 - Initialize Spine Workbench App Scaffold

## 背景
当前项目是 Spine Workbench，一款桌面工具型的 Spine 辅助生产软件。第一版重点是从单张角色图出发，完成导入、预览、人工修正、导出这条最小闭环。

## 本次任务目标
初始化一个可运行的桌面应用脚手架，为后续功能开发做准备。

## 技术要求
- 优先使用 Electron + React
- 目录放在 `app/` 下或合理的工程结构中
- 保持结构清晰，便于后续继续加功能

## 本次只做这些
1. 初始化基础工程
2. 提供一个主窗口
3. 提供一个空白首页
4. 首页包含：
   - 项目名 Spine Workbench
   - 一个“导入图片”按钮占位
   - 左中右三栏布局占位
5. 提供基础启动说明

## 不要做这些
- 不要接 AI
- 不要实现真正拆件逻辑
- 不要实现真正导出逻辑
- 不要过度设计 UI

## 交付物
- 可运行的基础工程
- 清晰的目录结构
- README 或启动说明

## 验收标准
- 本地可以启动
- 能看到桌面应用窗口
- 界面中能看到三栏布局基础框架
- 代码结构不混乱
