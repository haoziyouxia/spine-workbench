# trae-task-107-export-readiness-post-freeze-single-gap-closure-if-needed

## 任务概述
仅在 106 明确判定顶部状态区仍存在唯一极小缺口时，针对该缺口做最后一次闭口处理；若 106 已建议冻结，本章不得执行。

## 任务目标
1. 只补齐 106 指定的唯一残余缺口
2. 保持改动极小且紧邻顶部状态区主线
3. 为最终冻结结论提供闭环依据，而不是重新开启一轮 polish

## 实现要求
1. 进入本章前，必须先在 106 中明确写出唯一残余缺口是什么
2. 不得顺手扩展第二个问题面，不得借机重做顶部区域
3. 回写时必须明确说明“本章是对 106 唯一残余缺口的闭口，不是新一轮 polish”

## 验收标准
- 改动范围与 106 指定缺口一一对应
- 没有扩展到顶部区域之外，没有新增交互或重构
- 能支撑后续明确给出冻结闭环说明
