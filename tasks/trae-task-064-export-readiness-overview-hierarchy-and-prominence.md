# Trae Task 064 - Export Readiness Overview Hierarchy and Prominence

## 背景
在任务063已经整理状态按钮文案与动作一致性的基础上，继续优化导出准备度区域中"项目总览信息"的层级与显著性，让用户进入区域后，能更快识别当前整体状态、关键阻塞数量和下一步关注重点。

## 本次任务目标
优化导出准备度区域顶部或关键摘要区的信息层级，强化关键信息的可读性。

## 本次只做这些
1. 优化导出准备度区域顶部或关键摘要区的信息层级
2. 强化"当前整体状态 / 阻塞数量 / 建议优化数量 / 是否可导出"等信息的可读性
3. 让最关键的信息先被看到，次要信息后看到
4. 保持轻量，不做复杂面板系统或重型仪表盘

## 实现范围
- 导出准备度区域顶部的信息层级优化
- 关键摘要区的视觉主次调整
- 文案顺序优化

## 实现要求
1. 优先通过排版层级、视觉主次、文案顺序来增强理解效率
2. 如果当前存在阻塞项，要让阻塞信息比建议优化项更显眼
3. 如果当前已接近就绪，要让"可继续导出 / 仍需留意的点"表达更清楚
4. 保持与现有导出准备度交互逻辑一致
5. 不要引入复杂评分系统、复杂工作流面板、复杂筛选器、复杂设置系统

## 明确不做
- 独立新页面
- 重型统计仪表盘
- 多层复杂折叠交互系统
- 与导出准备度无关的大改

## 验收标准
- 用户进入导出准备度区域后，能更快看懂当前整体状态
- 阻塞项、建议项、可导出状态之间的主次关系更清楚
- 信息层级更稳定，不靠阅读长段文字才能理解当前状态
- 保持轻量自然，不演变成复杂系统

- 突出显示整体状态（就绪/阻塞/可导出）
- 阻塞数量使用更醒目的样式
- 建议优化数量使用次要样式
- 添加清晰的状态标签
