# Trae Task 038 - Save Before Close Flow Polish

## 背景
当前已经有更接近 Electron 原生的未保存关闭处理。下一步可以补一层流程打磨，让“保存并关闭”的体验更完整、更可靠。

## 本次任务目标
完善保存并关闭流程的细节反馈。

## 本次只做这些
1. 当用户选择“保存并关闭”时，清楚显示保存结果
2. 如果保存失败，不应直接关闭窗口
3. 失败时给出明确原因或至少明确失败提示
4. 保存成功后再继续关闭流程
5. 与现有 dirty state 逻辑保持一致

## 要求
- 第一版优先求稳
- 不要做复杂后台保存队列
- 重点是避免误丢数据

## 验收标准
- 保存成功时正常关闭
- 保存失败时窗口不会被误关闭
- 用户能清楚知道当前发生了什么
