# trae-task-075-export-readiness-header-mobile-scanability

## 任务概述
在 074 之后，检查顶部状态区在较窄宽度或紧凑视口下的扫读体验，避免在更窄布局下重新变挤、变乱。

## 任务目标
1. 优化顶部状态区在窄宽度下的阅读和排列
2. 避免按钮、统计项、状态描述在窄视口下互相挤压
3. 保持轻量，不做复杂响应式系统重构

## 实现要求
1. 仅做必要的响应式细化
2. 不为移动端单独做一套完全不同结构
3. 保持 064-074 的整体一致性

## 验收标准
- 在窄视口下顶部状态区仍能清晰阅读
- 按钮和统计项不互相挤压
- 保持整体布局稳定

## 实现方案

### 核心思路
添加必要的响应式样式，确保在窄视口下布局仍然合理。

### 具体实现
- 添加媒体查询调整窄视口下的间距和布局
- 优化按钮和统计项的换行行为
- 保持核心结构不变

## 交付结果

### 修改文件
1. `app/src/renderer/index.css` - 添加响应式样式
2. `tasks/trae-task-075-export-readiness-header-mobile-scanability.md` - 任务文件

### 验证方法
1. 在 `app/` 目录运行 `npm run build` 确认构建成功
2. 调整浏览器宽度，验证窄视口下的布局效果
3. 确认按钮和统计项不互相挤压
