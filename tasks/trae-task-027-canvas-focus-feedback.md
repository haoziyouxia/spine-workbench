# Trae Task 027 - Canvas Focus And Locate Feedback

## 背景
当前已经有“跳转到部件编辑”能力。下一步需要让画布端的定位反馈更像编辑器，而不只是选中状态变化。

## 本次任务目标
增强跳转定位后的画布聚焦和视觉反馈。

## 本次只做这些
1. 从列表/校验面板跳转到目标对象时，画布自动聚焦到目标区域
2. 提供短暂但清楚的高亮提示效果
3. 如果目标当前不可见，给出合理处理（例如临时提示或显式说明）
4. 不破坏现有缩放和平移交互

## 要求
- 第一版效果可以简单但清楚
- 不要做复杂动画系统
- 重点是定位后用户立刻知道“跳到了哪里”

## 验收标准
- 跳转后画布能明显聚焦目标
- 用户能快速识别目标对象
- 不影响原有画布操作稳定性
