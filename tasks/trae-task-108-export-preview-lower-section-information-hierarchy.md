# trae-task-108-export-preview-lower-section-information-hierarchy

## 任务概述
在 105-107 对顶部状态区完成阶段性冻结后，继续收口 ExportPreview 下半区的信息层级，让“项目信息 / 校验结果 / 目录结构”之间的阅读顺序更清晰，避免顶部已简化但下半区仍显得割裂。

## 任务目标
1. 调整 ExportPreview 下半区的信息层级与阅读顺序
2. 减少重复表达，避免和顶部 readiness 区块形成信息打架
3. 保持范围仅限 ExportPreview 页面，不扩展到其他面板

## 实现要求
1. 优先处理 `项目信息`、`ValidationResultComponent`、`目录结构` 三块之间的顺序、标题密度、间距与重复文案
2. 不重做顶部 readiness 主区，不推翻 105-107 已冻结的结论
3. 如发现某块内容已经被顶部充分表达，可做轻量降权、折叠或弱化，但不要直接删成功能缺口
4. 本章完成后，需要能一句话说明“用户扫描 ExportPreview 时，读完顶部后下一眼该看哪里”
