# Trae Task 023 - Box Selection On Canvas

## 背景
当前已经支持 Ctrl/Cmd 多选，但当部件数量继续增加时，单个点击多选会变慢。下一步可以补一个轻量的画布框选能力，提高批量选择效率。

## 本次任务目标
实现基础的画布框选多选。

## 本次只做这些
1. 在非创建模式下支持拖拽一个选择框
2. 选择框覆盖到的 part 进入选中集合
3. 与现有 Ctrl/Cmd 多选逻辑兼容或至少不冲突
4. 在画布上清楚显示选择框反馈
5. 不破坏现有单选逻辑

## 要求
- 第一版规则尽量简单
- 不要做复杂群组或套索选择
- 重点是提升批量选择效率

## 验收标准
- 用户可以通过拖框选择多个 part
- 选择结果清楚可见
- 与现有多选逻辑不混乱
