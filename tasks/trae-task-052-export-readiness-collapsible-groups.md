# Trae Task 052 - Export Readiness Collapsible Groups

## 背景
在任务051的基础上，已经实现了问题优先级分组。本任务需要进一步优化可读性，让用户在问题较多时不会被长列表压住。

## 本次任务目标
让导出准备度区域的分组可折叠，默认展开高优先级分组，中低优先级分组可折叠，提高整体可读性。

## 本次只做这些
1. 为优先级分组增加折叠/展开能力
2. 默认展开高优先级分组
3. 分组标题显示数量信息
4. 折叠状态清晰可见

## 实现要求
1. 支持三类分组独立折叠/展开
2. 高优先级分组默认展开且显眼
3. 折叠状态显示组内数量
4. 保持轻量，不做复杂功能

## 明确不做
- 复杂筛选系统
- 独立问题中心页面
- 拖拽排序
- 批量折叠控制面板

## 验收标准
- 问题较多时更易读
- 用户能快速聚焦高优先级问题
- 折叠/展开交互明确自然
- 数量和状态反馈清楚
