# Trae Task 051 - Export Readiness Priority Ordering

## 背景
在任务050的基础上，已经实现了问题展示、动作提供、选中同步和修复提示。本任务需要进一步优化问题的优先级排序，让用户能快速理解处理顺序。

## 本次任务目标
让用户面对问题列表时，能明确知道先修什么、后修什么，减少决策负担。

## 本次只做这些
1. 对导出准备度问题进行优先级排序
2. 视觉上突出高优先级问题
3. 区分三类优先级：阻塞导出、建议尽快修复、可稍后优化
4. 保持轻量，不做复杂系统

## 实现要求
1. 问题列表排序与优先级一致
2. 为每类优先级提供简洁的分组标题
3. 高优先级问题更容易被看到
4. 在现有机制上增强，不重造规则系统

## 明确不做
- 复杂评分算法
- 大型问题管理系统
- 可拖拽排序
- 独立页面或复杂筛选器

## 验收标准
- 用户能明显知道先修什么
- 排序和视觉层级一致
- 高优先级问题更突出
- 整体保持轻量清晰
