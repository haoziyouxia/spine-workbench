# Trae Task 044 - Grid And Snap UX Polish

## 背景
当前已经有基础网格和吸附功能。下一步需要做一点轻量体验打磨，避免用户不知道当前吸附状态或网格设置。

## 本次任务目标
提升网格和吸附功能的可见性与易用性。

## 本次只做这些
1. 更清楚显示当前网格大小和吸附开关状态
2. 提供轻量但直观的切换入口
3. 在吸附生效时给出适度反馈
4. 不破坏现有编辑流

## 要求
- 第一版只做轻量增强
- 不要做复杂网格设置面板
- 重点是让用户知道当前开了什么、吸附有没有生效

## 验收标准
- 用户能清楚看到当前网格与吸附状态
- 吸附生效时反馈明确但不过度干扰
